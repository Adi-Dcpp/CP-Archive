# Scripts

- `update_readme.py`: recomputes progress stats and (later) updates the README table.
- `count_solved.py`: prints total solved count.
- `stats.py`: prints solved count per rating bucket.
- `cf_fetch.py`: generates a problem folder from a Codeforces URL.

## Usage

```bash
python3 Scripts/count_solved.py
```

```bash
python3 Scripts/stats.py
```

```bash
python3 Scripts/update_readme.py
```

```bash
python3 Scripts/cf_fetch.py https://codeforces.com/problemset/problem/1903/A
```
